# Health Care Store

A modern Arabic storefront for medical, scientific, and laboratory supplies.

## Features
- Responsive Arabic landing page
- Product categories:
  - الرعاية الصحية
  - الكليات العلمية
  - معامل التحاليل الطبية
- Search functionality
- Shopping cart with quantity controls
- WhatsApp order submission
- Mobile-friendly layout
- Professional modern design

## Project Structure
- `index.html`
- `style.css`
- `script.js`

## How to Run
1. Download or clone the project.
2. Open `index.html` in your browser.
3. No build step is required.

## WhatsApp Order Setup
Open `script.js` and update this line with your business WhatsApp number:

```javascript
const WHATSAPP_NUMBER = "966500000000";
```

Replace it with your actual WhatsApp number, for example:
```javascript
const WHATSAPP_NUMBER = "966512345678";
```
